# 0mar.lol

صفحة bio شخصية وبسيطة جدًا لنشر النصوص والصور والفيديوهات والملفات لمتابعي تيك توك.

## الموجود في المشروع

- صفحة عامة عربية ومتجاوبة للجوال (وتعمل كتطبيق PWA قابل للتثبيت).
- إشعارات Web Push حقيقية لتعليقات الإدارة على iOS 16.4+ وAndroid.
- منشورات نصية، صور، فيديوهات وملفات قابلة للتحميل.
- تثبيت منشور ليظهر في أعلى الصفحة.
- تفاعل بدون حساب، مع تفاعل واحد لكل متصفح على كل منشور.
- تعليقات وردود بدون حساب — الاسم يُتذكر تلقائياً عبر كرز دائم (10 سنوات).
- ردود المالك تظهر بصورته الشخصية، والردود تُطوى وتظهر عند الطلب.
- التعليقات تُنشر مباشرة بدون موافقة مسبقة.
- صفحة دعم (`/support`) بباقات بالريال السعودي عبر Ziina.
- لوحة خاصة على `dashboard.0mar.lol` محمية بكلمة مرور (تُنقل تلقائياً من `/dashboard`).
- قاعدة بيانات SQLite وملفات مرفوعة محفوظة في Docker volume.
- Caddy لتشغيل `0mar.lol` و`dashboard.0mar.lol` مع HTTPS تلقائي.

## تشغيل محلي

يتطلب Node.js 22 أو أحدث.

1. انسخ `.env.example` إلى `.env`.
2. غيّر `ADMIN_PASSWORD` و`SESSION_SECRET`.
3. اترك `PUBLIC_HOST` و`DASHBOARD_HOST` فارغين (تُستخدم فقط في الإنتاج).
4. شغّل:

```bash
npm ci
npm run dev
```

يفتح الموقع على `http://localhost:3000` ولوحة التحكم على
`http://localhost:3000/dashboard`.

## النشر على VPS

1. وجّه سجلات DNS من نوع `A` للدومينات `0mar.lol` و`www` و`dashboard.0mar.lol` إلى عنوان الـ VPS.
2. ثبّت Docker وDocker Compose.
3. ارفع مجلد المشروع إلى الخادم.
4. أنشئ ملف الإعداد:

```bash
cp .env.example .env
openssl rand -base64 48
npm run push:keys
```

ضع ناتج OpenSSL في `SESSION_SECRET`، واختر كلمة مرور قوية في
`ADMIN_PASSWORD`. انسخ زوج VAPID إلى `VAPID_PUBLIC_KEY` و
`VAPID_PRIVATE_KEY`. لا تغيّر هذا الزوج بعد اشتراك الأجهزة، وإلا ستحتاج
الأجهزة إلى تفعيل الإشعارات من جديد.

في الإنتاج تُفعّل توجيه النطاقات تلقائياً: أي زيارة لـ `/dashboard` على
النطاق الرئيسي تنتقل إلى `dashboard.0mar.lol`، ولوحة التحكم تعمل على
جذر الدومين الفرعي (`/` و`/comments` و`/new` و`/edit/:id` و`/login`).

5. شغّل:

```bash
docker compose up -d --build
```

Caddy يحصل على شهادة HTTPS تلقائياً بعد وصول DNS إلى الخادم وفتح المنافذ
`80` و`443`.

## إشعارات تعليقات الإدارة

على iPhone أو iPad يلزم iOS/iPadOS 16.4 أو أحدث:

1. افتح `dashboard.0mar.lol` في Safari وثبّته عبر «إضافة إلى الشاشة الرئيسية».
2. افتح التطبيق المثبّت وسجّل دخول لوحة التحكم.
3. اضغط زر الجرس واسمح بالإشعارات.

تُحفظ اشتراكات الأجهزة في SQLite، وتُحذف الاشتراكات المنتهية تلقائياً.
مفتاح VAPID الخاص يبقى على الخادم ولا يُرسل للمتصفح.

## النسخ الاحتياطي

كل المنشورات والردود والتفاعلات والملفات المرفوعة موجودة في volume باسم
`omar-resources_omar_data`. خذ نسخة احتياطية منه بشكل دوري.

عند تشغيل الخادم تُفحص مجلد `uploads/` ويُحذف تلقائياً أي ملف لا يشير
إليه أي منشور (منشورات محذوفة أو تعديلات يدوية)، وملفات المسودات تبقى
محفوظة.

محلياً (خارج Docker): البيانات في مجلد `data/` داخل المشروع
(`data/omar-resources.sqlite` + `data/uploads/`).
